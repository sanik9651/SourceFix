# SourceFix — Ремонт поврежденных файлов онлайн

**SourceFix** — это высокопроизводительный веб-инструмент для восстановления поврежденных файлов прямо в вашем браузере.

🌐 **Демо онлайн**: [https://sanik9651.github.io/SourceFix/](https://sanik9651.github.io/SourceFix/)

---

## ⚡ Особенности

* **100% Конфиденциальность**: Файлы обрабатываются локально в вашем браузере (Client-Side). Никакие ваши данные не передаются на сторонние серверы.
* **Без ограничений**: Восстанавливайте файлы любого размера без очередей и водяных знаков.
* **Глубокая реконструкция (Deep Recovery)**: Слепое сканирование старт-кодов NAL (H.264), аудиопотоков ADTS (AAC), чанков PNG/JPEG и оглавления ZIP/Office.
* **Адаптивный интерфейс**: Тёмная и светлая темы оформления, 3D-интерактив на Three.js, встроенный видео- и фотоплеер для мгновенного предпросмотра результата.

---

## 📁 Поддерживаемые форматы файлов

| Категория | Форматы | Возможности восстановления |
| :--- | :--- | :--- |
| **Видео** | `MP4`, `MOV` | Восстановление стёртых `ftyp`, отсутствующих/повреждённых атомов `moov`, отбрасывание сбойных секторов `mdat`, нормализация PTS/DTS |
| **Аудио** | `MP3` | Детектирование синхрослов MPEG Audio, удаление битого мусора перед фреймами |
| **Изображения** | `JPEG`, `JPG`, `PNG` | Восстановление маркеров SOI/EOI, чанков IHDR/IDAT, автоподбор пропорций |
| **Документы** | `DOCX`, `XLSX`, `PPTX` | Реконструкция каталога Central Directory, восстановление `[Content_Types].xml`, `word/document.xml`, `xl/workbook.xml` |
| **Архивы** | `ZIP` | Сканирование сигнатур `PK\x03\x04`, исправление битых заголовков Local File Headers |

## 🚀 Локальный запуск

Сайт работает без сборщиков и бэкенда на чистом современном HTML5 / ES-модулях:

```bash
# Клонируйте репозиторий
git clone https://github.com/sanik9651/SourceFix.git
cd SourceFix

# Запустите любой локальный HTTP-сервер, например:
python3 -m http.server 5500
# или
npx serve .
```

Откройте в браузере: `http://localhost:5500`.
